# Aurora

A calm habit-tracking app. This repository contains the mobile client and its
documentation set.

Start with [the documentation manifest](docs/00-manifest.md).

## Layout

- `mobile/` — React Native client (has its own `CLAUDE.md` with scoped rules)
- `docs/` — architecture, ADRs, product intent, UX flows, design tokens
- `src/premium/` — entitlement logic shared with the backend
