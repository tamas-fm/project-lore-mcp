# Product intent

## Emotional progression

Onboarding must feel like a calm morning, not a signup funnel: curiosity →
ease → quiet confidence. Each screen removes anxiety rather than adding
motivation pressure.

## No urgency

Aurora never uses urgency mechanics. No countdowns, no "streak at risk"
alarms, no red badges. Habit repair is framed as self-compassion, because the
target user abandons apps that shame them.

## Premium restraint

Premium UI uses gold sparingly — accents and moments of delight only, never
full backgrounds. Scarcity of gold is what makes premium feel considered
rather than loud.
