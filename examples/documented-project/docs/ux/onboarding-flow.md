# Onboarding UX flow

Read with: [Product intent](../product/intent.md)

## Flow

1. Welcome — one sentence, one illustration, no buttons except continue.
2. First habit — user picks a single starter habit; no lists of twenty.
3. Gentle schedule — default reminders off; user opts in.
4. Done — the app opens directly on today, already usable.

## Screen conventions

Each onboarding screen animates in with the standard entrance transition
defined in [mobile motion](../design/mobile-motion.md).
