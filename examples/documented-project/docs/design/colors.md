# Colors

## Application tokens

- `surface.calm` — #F7F5F0, default background.
- `accent.dawn` — #E8A87C, primary interactive accent.
- `premium.gold` — #C9A227, premium accents only (see product intent).

## Usage rules

`premium.gold` appears only on entitlement-gated elements and never covers
more than 10% of a screen.
